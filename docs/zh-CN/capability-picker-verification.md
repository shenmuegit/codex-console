# 技能与插件选择器验证

输入框选择器完整提供技能、插件和连接器浏览、用途搜索、详情与插件技能列表、
可移除的多选标签、收藏和最近 20 项选择。发送时仍以原生身份和可用性校验为准。

首次功能开发采用 Superpowers 的先回归检查、再修复和独立只读复核流程，并结合
UI/UX Pro Max 检查现有字体、灰阶主题、焦点、触摸目标和响应式布局；没有增加
应用运行依赖。

## 自动化检查

```bash
node --test web/test/capabilities.test.mjs web/test/composer.test.mjs web/test/completion-interactions.test.mjs
cd web
npm test
```

定向检查覆盖已打开会话和实际目录限制、显式强制刷新、工作区与应用分开加载、完整连接器分页及
分页部分失败、原生加载错误、类型化输入与发送前拒绝、引用前后的编辑及重名、
过期响应、输入法、焦点、跨页面收藏，以及存储禁止、损坏和容量耗尽。收藏和
最近使用按主机、目录隔离；未能写入存储的内存记录在当前页面重建控制器后仍保留。

加载回归检查覆盖技能不等待应用目录、应用加载期间本地插件仍可选择、迟到应用响应
不打断插件详情或已选内容，以及已读目录重开时不重复请求。缓存按会话、工作目录和
原生连接代数隔离；账号失效会丢弃待返回结果。主动刷新仍锁定旧条目，失败后移除
可选的过期内容。浏览器测试数据按请求的目录来源分别返回。

本次结果：65 项定向检查通过；完整 Web 套件 504 项通过，8 项仅适用于 Windows 的
ACL 检查在 Linux 上跳过，没有失败项。

## 直连接口耗时

修复前，强制发现的原生技能请求 412 毫秒返回，已安装插件请求 52 毫秒返回，但合并
响应一直等到 `app/list` 在 30,002 毫秒时超时。部署后，携带登录认证、直接通过 HTTPS
调用 `/api/capabilities` 的 `section: "workspace"` 连续三次分别耗时 169、171、172 毫秒，
均返回 180 个技能、8 个插件，没有来源错误。验证禁用了代理环境变量，并确认线上
客户端文件与本次修改一致。未重启现有原生后端，也未调用模型或插件。
外部应用目录的速度仍取决于原生服务和网络。

## 真实浏览器检查

使用已有 Playwright，或作为验证工具安装；可用
`python -m playwright install chromium` 安装它的 Chromium。这不是应用运行依赖。
脚本使用测试目录数据和临时 localhost 服务，不连接用户会话，也不会调用模型。

```bash
uv run --with playwright python web/test/capabilities-browser.py
# 也可以指定已安装的 Chromium：
uv run --offline --with playwright python web/test/capabilities-browser.py \
  --chromium /absolute/path/to/chrome --output /tmp/codex-console-capability-qa
```

首次功能的浏览器检查完成以下 9 组尺寸与主题，共生成 36 张截图。本次加载优化未
重跑该视觉检查；已更新按来源返回数据的浏览器测试文件并检查语法，验证采用上述
自动化检查和实际直连接口。

| 尺寸 | 主题 | 主要检查 |
| --- | --- | --- |
| 1280 × 850 | 浅色、深色 | 弹层定位在输入框上方 |
| 375 × 812 | 浅色、深色 | 全宽底部弹层与详情可读性 |
| 667 × 375 | 深色 | 横屏滚动及底部操作可达 |
| 1024 × 500 | 浅色 | 低高度桌面窗口 |
| 820 × 420 | 深色 | 低高度桌面窗口 |
| 320 × 568 | 浅色 | 小手机与四个长名称已选标签 |
| 375 × 480 | 深色 | 缩小视口，模拟键盘占用空间 |

每组检查用途搜索、收藏及最近使用保存与主机隔离、插件内技能、多选和移除、
中文及 emoji 保留、原生提及身份、Escape 和焦点恢复、长名称滚动、横向溢出、
操作按钮可达性，以及 JavaScript 和控制台错误。截图包含列表、插件详情、
普通已选标签和四个长名称标签。`report.json` 记录尺寸与截图位置；默认输出在
仓库外的 `/tmp/codex-console-capability-qa`。

截图检查确认浅色和深色下的字体、主题一致性、换行和焦点可见性。浏览器迭代
修正了原生 dialog 的默认定位和宽度限制、低高度窗口底部操作被裁切，以及长标签
挤出输入框操作的问题。最终浏览器结果为 `passed`，没有控制台错误。

尚未测试真机键盘、Safari 或真实第三方插件调用。375 × 480 检查仅调整浏览器视口
高度，不代表操作系统键盘或真机输入法验证。
