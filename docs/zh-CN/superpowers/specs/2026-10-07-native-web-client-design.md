## 目标与范围

浏览器打开 `https://主机IP:端口`，操作现有 Codex 桌面的项目、聊天和运行中
任务。首版面向单用户、单主机；一个鉴权网关以桌面相同的 OS 用户运行。
聊天数据、登录和模型执行继续由桌面及其现有后端持有。

首个完整版本覆盖下表全部能力。分阶段用于控制交付顺序，并非省略后面的需求。

两项暂定语义等待用户澄清：

- “7天使用量”按账号周额度使用率、剩余率和重置时间处理；token 活动与费用
  是不同指标。
- “编辑工作目录”按修改项目显示名称、绑定路径处理；归档保留目录和会话。
  网页代码编辑器、实际移动磁盘仓库属于额外范围。

## 功能契约

| 能力 | 首版行为 |
| --- | --- |
| 项目工作目录管理 | 列出桌面项目；登记已有主机目录或创建新目录；编辑名称/路径绑定；归档、恢复。目录选择器浏览主机目录，不选择手机文件系统作为工作目录。 |
| 工作目录历史 | 修改绑定不搬文件、不改已有会话的 `cwd`。旧会话保留实际目录，新会话使用新绑定。归档隐藏项目，不停止任务、不删除文件。 |
| 会话管理 | 按项目列出、新建、打开、删除会话，显示原生运行/空闲/失败状态。提供真实原生线程 ID 的显示和复制。 |
| 读取聊天 | 历史分页；显示用户/助手消息、桌面可见的工具活动、文件与实时更新；加载旧消息时保持滚动位置。 |
| 发送与停止 | 发到当前原生线程；运行中的追问/排队交给桌面原生策略，并显示实际结果。停止通过原生中断动作，不杀桌面进程。 |
| 删除会话 | 使用原生删除，不以隐藏/归档或直接改数据库代替。一次明确确认；运行中先等待停止完成再删除。项目文件与已完成上传保留，双端列表反映删除。 |
| 上传文件/照片 | 原生文件/照片选择器，多选、预览、移除、串行上传队列。默认每文件 32 MiB，可配置；上传完成才发送附件。 |
| 下载聊天目标文件 | 将聊天里的文件引用转成经过认证的下载动作，保持原文件名和字节内容。按会话实际目录解析，项目修改绑定后旧文件引用仍可用。 |
| 模型与思考强度 | 从原生能力列表生成选项，仅显示该模型支持的强度。调整对下一条发送生效，保留草稿；后端重路由时显示实际模型。 |
| 默认最大授权 | 新会话和后续发送默认完全文件/网络访问、无需执行审批；服从原生托管限制，显示实际生效值。 |
| 上下文使用量 | 显示最近活动上下文 token、可用时的模型窗口和原生使用/剩余比例；压缩、换模型后更新。缺失显示不可用，不伪造为 0。 |
| 7天使用量 | 显示账号周额度已用/剩余比例及重置时间，分额度桶展示。是账号指标，不是某个项目的累计量。 |
| `@` | 搜索并选择文件、目录、会话，以及可用应用/插件；保留准确的原生引用描述和权限。 |
| `$` | 按当前工作目录列出技能，把选中的技能名称/路径和可见调用一起发送。 |
| `/` | 展示当前桌面实际支持的命令；按原生动作、界面动作或提示命令分别处理，不虚构 `commands/list` RPC。 |

## 最小架构

浏览器连接带鉴权的 HTTP/WebSocket 网关。网关通过一个桌面适配器接入选定
桌面实例的现有 IPC 和原生操作。适配器只转换协议，不建立第二套聊天库，
不启动一套独立 Codex 引擎。

- 会话、运行状态、账号、原生项目登记、模型能力和用量以桌面为准。
- Web 专有别名、必要的项目归档覆盖状态及界面偏好用仓库外一个小 JSON 文件
  保存。项目变更若缺少受支持的桌面入口，明确补桥接能力，不悄悄另建无关的
  项目注册库。
- 内存只缓存当前订阅会话的快照和待确认请求关联；重连先取得权威状态再接增量。
- 适配一个已验证的桌面协议/构建，记录能力；不支持的动作明确报错，不做通用
  多提供商或插件框架。

接入门槛通过后的拟定文件边界：

| 文件 | 职责 |
| --- | --- |
| `web/package.json`、锁文件 | Node.js 24；[ws](https://github.com/websockets/ws) 提供 WebSocket 服务，[markdown-it](https://github.com/markdown-it/markdown-it) 安全渲染 Markdown。 |
| `web/server.mjs` | HTTP/HTTPS、用户登录、API 白名单、WebSocket 会话、项目操作与偏好。 |
| `web/desktop.mjs` | IPC 帧、受支持握手、请求关联、原生操作映射、能力和快照/事件。 |
| `web/files.mjs` | 流式上传、原生附件描述、经过验证的文件引用下载。 |
| `web/public/index.html`、`app.js`、`styles.css` | 响应式项目列表、会话列表、聊天、模型/用量及连接状态。 |
| `web/public/composer.js` | 草稿、附件、`@`、`$`、`/` 菜单、原生输入描述与输入法处理。 |
| `web/test/*.test.mjs` | 内置 `node:test`，合成协议样本和 HTTP/WS/文件/输入检查。 |

静态资源由同一个网关提供，只发布固定 Markdown 资源；使用浏览器原生文件
选择和剪贴板 API，不需要前端构建步骤。交互层级为项目 → 会话 → 聊天；
桌面可并列三栏，手机一次显示一级。

## 授权与数据

Web 统一授权预设为 `full`。适配器在新建线程时映射为原生
`sandbox: "danger-full-access"`、`approvalPolicy: "never"`；发送轮次使用原生
`sandboxPolicy` 表达。命名 `permissions` 配置与 sandbox 字段互斥。
读取会话不改变已经运行轮次的授权，原生策略拒绝时显示实际限制，不绕过。

最大执行授权不取消网页登录、OS 所有权检查或原生身份/工具验证。原生要求
补充信息、审批时仍要有可见的应答路径，并指定单一应答方。

配置、TLS 私钥、登录凭据和应用状态保存在仓库外：
`~/.config/codex-console-web/` 与 `~/.local/state/codex-console-web/`，遵循 XDG
覆盖值。初次部署以桌面已启动并登录为前提。主机 IP 入口使用 HTTPS/WSS、
认证 Cookie、来源检查和明确的 API 白名单，不公开任意 IPC 调用。

上传使用元数据请求加原始二进制请求体，不手写 multipart 解析器。流式计算
字节数，失败清理未完成文件；完成的附件保留供原生会话后续读取。
下载使用绑定原生主机/会话的文件引用 ID 与经过验证的真实路径，不提供任意
路径或任意 URL 抓取入口。Markdown 禁用原始 HTML 并验证链接；可执行上传
作为附件下载，不作为网页执行。
普通文件必须走桌面的文件上下文/附件表达，照片走图片输入；不虚构通用二进制
`UserInput` 类型。原生后端/模型限制更低或拒绝附件时，遵循其限制并保留草稿。

## 输入、设置和用量规则

- 选中的 `@` 保留原生结构化引用。应用/插件、文件上下文、会话引用使用不同
  表达；引用其他会话不隐含向其发送消息的授权。
- `$` 技能选择包含原生 `skill` 输入项。未匹配的美元表达式、邮箱、路径、
  代码保持原文；`/` 仅在正确命令位置、按实际支持目录补全。
- 富输入范围采用原生 UTF-8 字节偏移。JavaScript UTF-16 光标位置需正确转换，
  覆盖中文与 emoji。输入法确认不触发发送或菜单选中；Enter 发送，Shift+Enter 换行。
- 使用稳定的客户端消息/请求 ID 做关联。原生 `clientUserMessageId` 的存在
  不代表保证幂等。断线后不自动重放结果不确定的发送/新建/删除，先核对原生
  状态，保留草稿或待确认状态。
- 优先用桌面已经计算的上下文状态。公开协议的 `last.totalTokens` 是最近
  活动上下文，`total.totalTokens` 是会话累计值；原生比例计算还扣除固定基线。
  不拿累计 token 估算当前上下文。
- 周额度优先使用 `rateLimitsByLimitId`，必要时兼容旧快照。
  `windowDurationMins == 10080` 才是七天；不默认 `secondary` 一定是周额度，
  不把不同桶比例相加。账号变化清除旧缓存，null 显示不可用。
- 模型和强度来自原生列表，仍受账号策略限制。模型目录不是可用权限保证；
  原生拒绝时保留草稿并报实际状态，不偷偷换模型。

## 交付顺序与验收门槛

遵循仓库 AGENTS.md：每个独立实现问题完成验证、commit、push，确认远端
包含提交后，再开始下一个。

| 阶段 | 交付 | 通过条件 |
| --- | --- | --- |
| 0：桌面接入验证 | 记录 IPC 握手/schema、实例身份和操作能力，只做可丢弃的桥接探针。 | 读取真实已有桌面线程并收到一致的实时变化，不另建引擎；新建/发送/停止/删除仅在临时测试会话演示。确认项目、附件、设置、用量及引用的受支持路径。 |
| 1：可用主流程 | 鉴权网关、响应式导航，项目新建/编辑/归档/恢复，会话管理，历史/实时聊天，发送/停止，复制 ID，实际最大授权和原生待输入处理。 | 双端操作的是同一原生线程，生命周期变化双端可见；归档保留文件/线程；改绑定不改旧线程路径。 |
| 2：文件 | 文件/照片选择、进度/预览、原生附件交付、聊天文件下载。 | 中文文件名文档与照片进入原生线程；生成的本机目标文件按原名、逐字节正确下载；上传失败保留草稿和已有数据。 |
| 3：模型与用量 | 原生模型/强度选择、上下文、账号周额度与重置时间。 | 只显示支持的强度，下一轮设置实际生效；压缩/换模型后上下文正确；多窗口、缺失额度数据如实处理。 |
| 4：输入与交付 | `@`、`$`、`/` 原生引用/命令、手机/输入法、断线恢复、打包与中英文运维说明。 | 引用以原生身份到达 Codex，命令产生真实效果，断线不重复发送；桌面/手机流程通过。 |

第 0 阶段若无法取得合法的写入/订阅通道，客户端实现停在该门槛，提出桌面侧
桥接改动。共享 app-server 只有在桌面本身也能接入同一实例、并验证桌面级行为
后才是备选。不能用独立后端冒充当前桌面，或直接修改其私有 SQLite。

## 必要验证

| 条件 | 预期 |
| --- | --- |
| 网页打开时桌面新建/发送聊天 | 原生 ID、消息顺序和实时状态一致；版本缺口触发重取快照。 |
| 双击发送或写入已接受但回包丢失 | 关联/核对状态，不自动生成重复轮次或空会话。 |
| 删除运行中会话 | 先停止；拒绝/超时保留历史与项目文件。 |
| 有旧会话的项目改绑定/归档 | 旧 `cwd` 与产物引用仍有效；归档保留磁盘数据及运行任务。 |
| 中文、emoji、输入法、粘贴代码和邮箱 | UTF-8 范围正确，不误发消息、不误展开技能或执行命令。 |
| 上传超限/中断/无权限/磁盘满，伪造下载目标 | 明确失败、清理半文件，不串会话，不任意读取主机文件。 |
| 模型下线、强度不支持、额度/窗口为 null | 保留草稿并显示原生状态，不伪造设置或 0 用量。 |
| 原生授权限制或待身份验证 | 显示实际策略和待处理动作，不伪造同意。 |
| 未登录/跨来源访问、不安全 Markdown 链接/HTML | 网关拒绝或安全展示，不暴露 IPC 与凭据。 |

实现存在后运行 `node --test web/test/*.test.mjs`，再以临时数据验证真实桌面，
以真实手机验证输入法、复制、照片上传、下载和键盘布局。本次只改规划文档，
验证差异、链接和需求覆盖，不把尚未实现的运行测试写成已通过。
